Privacy Policy

Effective and last updated: October 2, 2026

Current status: YouTube Data API collection and analysis are disabled while the owner seeks a policy determination for this proposed cross-source research use. The practices below describe the intended handling if collection is later approved and enabled.

Who this policy covers

Investment Research Agent is software operated locally by one individual for personal Taiwan equity market research. It is not a public application and has no external users or user accounts. This policy covers the software's proposed use of YouTube Data API Services and this static disclosure website.

YouTube API Services and data accessed

If enabled, the software will use only documented YouTube Data API v3 methods to access public channel, video, and comment information. Channel discovery, when used, returns suggestions for human review; a person must approve a channel before comments are collected. The software does not scrape YouTube pages or use YouTube sign-in credentials or OAuth.

For approved public videos and comments, the software may process comment text, comment and thread IDs, publication times, public like and reply counts, and limited publisher/video information such as channel or video IDs, channel names, and video titles. These fields support source attribution, deduplication, deletion tracking, and research analysis.

The software does not collect or store commenters' display names, commenter channel IDs, profile URLs, or avatars. It does not attempt to identify a commenter or connect a comment to a personal profile.

How information is used

Comment text is analyzed locally on the project owner's computer to derive aggregate discussion topics, attention, and sentiment about Taiwan equity market discussion. Those aggregate signals may be statistically compared with public Taiwan stock prices and public company announcements. They are the owner's independent analysis, not metrics published by YouTube.

This is cross-source market research, not an assessment of viewer satisfaction with YouTube channels or videos. Its eligibility under Google's derived-metrics policies has not been determined; no use is represented as approved.

The software does not profile individuals, infer sensitive traits, sell or disclose YouTube API data to others, use the data to train or fine-tune a model, or place brokerage trades. Analysis uses a locally hosted model; no third-party cloud model or advertising analytics service is used by the software.

Retention and deletion

Raw comment text, video-title text, and text evidence snippets are designed to be deleted no later than 30 days after collection. The current software design preserves comment/source IDs, timestamps, public counts, ticker mappings, and structured per-comment research fields locally after that text purge; those records do not currently have a separate automatic expiry. Reports use aggregate statistics and do not include comment text, titles, or commenter identity.

Because the preserved identifiers and structured records may be subject to YouTube API data-storage limits, the owner will not enable collection until the applicable policy permits this handling or the retention behavior is changed to meet the policy. Any extended storage of public statistics or derived metrics would occur only if permitted for the approved use case and within the retention period allowed by the then-current policies. This policy does not claim permission to retain data beyond the standard limits.

Sharing, security, and access

The research software is local to the owner's computer and is not distributed as a public service. YouTube data are not sold, shared with advertisers, or made available to other users. The owner uses local access controls and removes API data according to the retention rules above. GitHub Pages hosts this disclosure website; GitHub may process ordinary technical request information under its own privacy terms.

This website

This static site does not provide application accounts or collect form submissions. It uses no advertising pixels, third-party analytics scripts, or tracking cookies. The hosting provider may process standard web request and security logs. See the GitHub Privacy Statement.
